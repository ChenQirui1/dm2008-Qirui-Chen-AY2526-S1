# Mini Project - Flappy Cat

## Sketch Concept

Flappy Bird-style game featuring animated cat sprites navigating through space obstacles. The game includes physics-based movement with gravity and flapping mechanics, procedurally generated pipes (space rocks), collision detection, scoring system, and multiple selectable cat characters. The background scrolls infinitely.

## Sketch Instructions

- **Space Bar**:
  - Before game starts: Begin the game
  - During game: Make the cat flap upward
  - After game over: Restart the game
- **Change Cat Button**: After game over, click to cycle through 10 different cat characters for your next game
- **Gameplay**:- Just flappy bird
- The cat sprite changes animation based on movement (jumping vs falling)
- Pipes spawn automatically every 1.5 seconds with randomized gap positions
