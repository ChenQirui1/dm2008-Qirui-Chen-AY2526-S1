# Activity 3a - Array Color Sampler

## Sketch Concept

This sketch demonstrates array manipulation using changing color palette. Circles are stacked vertically, each displaying a different color from the palette array. Users can add or remove colors.

## Sketch Instructions

- **'+' Key**: Add a new circle with random color to the bottom of the stack
- **'-' Key**: Remove the last circle from the stack
- **'\_' (Underscore) Key**: Remove the first circle from the stack
- **Mouse Hold**: Replace the first color with a new random color continuously
- Colors are logged to the console when added or removed
