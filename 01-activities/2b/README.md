# Activity 2b - Generative Pattern Making

## Sketch Concept

This sketch generates a grid-based pattern using nested loops. Shapes (circles and rectangles) are placed in a regular grid with random sizes. The pattern alternates between circles (every 100 pixels on the x-axis) and rectangles, with options to toggle between colored fills and outlined strokes.

## Sketch Instructions

- **'1' Key**: Switch to monochrome mode (outlined shapes with no fill)
- **'2' Key**: Switch to color mode (random colored fills)
- The pattern continuously regenerates at 10 frames per second
- Dark background with semi-transparency creates layering effects
