# Activity 4a - Interactive Cookie Object

## Sketch Concept
This sketch demonstrates object-oriented programming by creating a Cookie class. The cookie can move around the canvas and collect chocolate chip toppings when clicked. It showcases properties (flavor, size, position, toppings) and methods (show, move, addTopping, moveCookie) working together in a class.

## Sketch Instructions
- **Arrow Keys**: Move the cookie in the corresponding direction
  - **Up Arrow**: Move up
  - **Down Arrow**: Move down
  - **Left Arrow**: Move left
  - **Right Arrow**: Move right
- **Mouse Click**: Add a chocolate chip topping at the mouse position
- Toppings move along with the cookie when you use arrow keys
