# Activity 10 - Interactive Grid Pattern with UI Controls

## Sketch Concept

An upgrade to a previous sketch(2b), allowing grid adjustment.

This advanced pattern-making sketch features a DOM-based UI control panel that allows users to dynamically modify the grid pattern. Users can adjust grid density, toggle between color modes, and switch shape types using dropdown menus and sliders.

## Sketch Instructions

- **Grid Size Slider**: Adjust the number of shapes in the grid (1-10)
- **Color Mode Dropdown**:
  - **Colour**: Shapes filled with random colors
  - **Monochrome**: Outlined shapes with no fill (white strokes)
- **Shape Type Dropdown**:
  - **Circle**: Display circular shapes
  - **Square**: Display square shapes
- All UI controls are located in the control panel at the top-left
- Shapes have random sizes within the calculated grid space
- Pattern regenerates at 10 frames per second with semi-transparent background for layering effects
