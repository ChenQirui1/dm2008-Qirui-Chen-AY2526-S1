# Activity 4b - Objects in Motion

## Sketch Concept

This sketch creates a particle system with multiple Agent objects moving independently across the canvas. Each agent has properties like position, velocity, size, color, and lifespan. Agents automatically bounce off walls and gradually fade away. The agents change form on contact with the edges. Exploring different elements to add like text, shapes and emojis.

## Sketch Instructions

- **Mouse Click**: Add a new agent at the mouse position with random properties
- **'C' Key**: Clear all agents from the canvas
- Initial spawn of 12 random agents on startup
