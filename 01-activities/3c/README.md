# Activity 3c - Painting Application

## Sketch Concept

This is an interactive painting application with multiple brush types and customizable options. Users can draw on the canvas using different brushes (circle, random colors, text), change colors from a preset palette, adjust brush size, and clear the canvas.

## Sketch Instructions

- **Mouse Hold**: Draw with the current brush
- **Number Keys (1-3)**: Select brush type
  - **1**: Circle brush
  - **2**: Random color brush
  - **3**: Text brush (cycles through words)
- **'c' or 'C' Key**: Cycle through color palette
- **'+' Key**: Increase brush size
- **'-' Key**: Decrease brush size
- **'x' or 'X' Key**: Clear the canvas
- Drawing persists until canvas is cleared manually
