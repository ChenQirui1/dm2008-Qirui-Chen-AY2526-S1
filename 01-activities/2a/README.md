# Activity 2a - Mode Switch Animation

## Sketch Concept

This sketch is inspired by Rene Magritte's "Treachery of Images".

A shape moves across the screen, changing between a circle and square based on mouse position. The background color and shape size can be controlled through keyboard input.

## Sketch Instructions

- **Mouse Position**:
  - Left half of canvas: Displays "This is not a circle" with a circle shape
  - Right half of canvas: Displays "This is not a square" with a square shape
- **Number Keys**:
  - **1**: Red background, size 100
  - **2**: Green background, size 150
  - **3**: Blue background, size 200
  - **Other keys**: Reset to grey background
- **'s' Key**: Record and save a 5-second animated GIF
- The shape automatically moves from left to right and wraps around
