# Activity 1a - Pixel Art Cat

## Sketch Concept

This sketch creates a simple pixel art cat face using basic shapes. The cat features pointed ears, round eyes with yellow highlights, and a pink nose. The sketch demonstrates basic drawing functions and custom shape creation using rectangles and ellipses.

## Sketch Instructions

- **Option/Alt Key**: Toggle visibility of the helper grid overlay
- **Shift Key**: Change overlay color between black and white
- The sketch runs automatically at 10 frames per second
- Click on the preview window to enable keyboard controls
