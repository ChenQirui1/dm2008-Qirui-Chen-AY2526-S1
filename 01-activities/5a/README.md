# Activity 5a - Colliding Balls

## Sketch Concept

BALLSSSSS

This sketch demonstrates collision detection between multiple bouncing balls. Five balls move around the canvas, bouncing off walls and detecting collisions with each other. When balls collide, they change color from blue to pink.

## Sketch Instructions

- No direct user interaction required
- Balls change to **pink** when they collide with each other
- Balls return to **blue** when they separate
- Balls bounce off all canvas edges
- Each ball has random velocity for varied motion patterns
